# 📐 AI SVG Чертежник ГОСТ (PWA)

**AI SVG Чертежник ГОСТ** — это легкое прогрессивное веб-приложение (PWA) для автоматизированного и ручного создания инженерных чертежей форматов **А4** и **А3** в векторном формате **SVG** по стандартам ЕСКД (ГОСТ), оснащенное искусственным интеллектом **Google Gemini** для распознавания эскизов и генерации чертежей по описанию.

Приложение работает прямо в браузере телефона или ПК, устанавливается на главный экран и поддерживает офлайн-режим.

---

## ✨ Основные возможности

### 1. 📝 Гибкий штамп (Основная надпись) и рамка ГОСТ
* **Форматы листов:** А4 (`210×297 мм`) и А3 (`297×420 мм`).
* **Ориентация:** Вертикальная (книжная) и горизонтальная (альбомная) с правильными отступами рамки по ГОСТ (`20 мм` слева для подшивки, по `5 мм` с остальных сторон).
* **Привязка:** Штамп всегда автоматически располагается в правом нижнем углу внутренней рамки.
* **Сдвиг левого края (Изменение размера):** Возможность плавно уменьшать ширину штампа (от `185 мм` до `80 мм`), если он упирается в левую рамку или нужно освободить место на поле чертежа — все внутренние графы масштабируются пропорционально.
* **Настройка строк и сложности:**
  * Регулировка количества верхних дополнительных строк изменений (`Изм. Лист № докум.`) от `0` до `6`.
  * 4 режима отображения: **Полный ГОСТ (Форма 1)**, **Упрощенный (Учебный)**, **Мини-штамп** и **Без штампа** (только рамка).

### 2. ⚙️ Параметрический генератор проекций
Автоматическое построение базовых машиностроительных деталей (*Ступенчатая втулка, Опорная плита, Вал со шпоночным пазом*) в трех режимах:
* **Три основных вида:** Проекционная связь (Вид спереди, Вид сверху, Вид слева) с автоматической отрисовкой осевых (штрихпунктирных) и невидимых (штриховых) линий.
* **Фронтальный РАЗРЕЗ:** Замена главного вида на разрез с открытием внутренних контуров и заливкой материала ГОСТ-штриховкой под углом `45°`.
* **Вынесенное СЕЧЕНИЕ (А-А):** Отрисовка линии сечения и выносной заштрихованной фигуры сечения.

### 3. ✏️ Ручное черчение примитивами и База деталей
* Построение по миллиметровым координатам: *Линии, Прямоугольники, Окружности, Размерные линии с авто-вычислением длины и стрелками, Зоны штриховки*.
* Поддержка линий ГОСТ: Основная (`0.7 мм`), Тонкая (`0.25 мм`), Штриховая (невидимая), Штрихпунктирная (осевая).
* **Пополняемая библиотека:** Сохранение собственных настроенных деталей и чертежей в память устройства (`localStorage`) с возможностью быстрого вызова и редактирования.

### 4. 🤖 ИИ Сканер и OCR (Google Gemini API)
* Распознавание деталей с **фотографий бумажных эскизов, скриншотов** или **текстового описания**.
* ИИ извлекает габариты, диаметры, название детали для штампа и координаты примитивов, после чего передает их в математическое ядро приложения для чистового черчения.
* Автоматическая подгрузка списка доступных моделей по вашему API-ключу (`gemini-flash-latest`, `gemini-3.5-flash`, `gemini-3.8-flash`, `gemini-pro-latest`, `gemma-4` и др.).
* API-ключ вводится внутри приложения и хранится **только локально на вашем устройстве**.

### 5. 💾 Экспорт и печать
* **Скачивание `.SVG`:** Векторный файл с точными размерами в миллиметрах (совместим с *AutoCAD, Компас-3D, CorelDRAW, Inkscape, Illustrator*).
* **Печать / Экспорт в `.PDF`:** Встроенный режим чистой печати листа А4/А3 без элементов интерфейса.
* **Встроенный учебник:** Подробная русскоязычная справка по всем функциям прямо в меню приложения.

## 🚀 Как пользоваться (Установка на телефон / ПК)

1. Перейдите по ссылке вашего опубликованного проекта на **GitHub Pages** (например: `https://ваш-логин.github.io/имя-репозитория/`).
2. В меню мобильного браузера (Chrome / Safari) выберите **«Добавить на главный экран»** (*Установить приложение*).
3. Запустите приложение с рабочего стола.

---

## 🔑 Настройка ИИ Google Gemini

1. Получите бесплатный API-ключ в [Google AI Studio](https://aistudio.google.com/).
2. Откройте в приложении вкладку **«🤖 ИИ Сканер (OCR)»**.
3. Вставьте ключ в поле `Ваш API Ключ` (он сохранится автоматически).
4. Нажмите кнопку **«🔄 Проверить ключ и обновить список моделей»**, чтобы выбрать актуальную для вашего аккаунта модель (рекомендуется `gemini-flash-latest` или `gemini-3.5-flash`).
5. Прикрепите картинку эскиза или напишите задание текстом и нажмите **«✨ Распознать и начертить через ИИ»**.

## 📂 Структура проекта

Все файлы расположены в корневой директории для удобного управления через мобильную веб-версию GitHub:

* `index.html` — Пользовательский интерфейс, адаптивная верстка, стили печати и встроенный учебник.
* `app.js` — Ядро генерации SVG, логика штампа ГОСТ, параметрический конструктор видов/разрезов/сечений и интеграция с Gemini API.
* `manifest.json` — Манифест Progressive Web App (иконка, цвета, полноэкранный режим).
* `sw.js` — Service Worker для кэширования и работы приложения без интернета.
* `install.md` — Пошаговая инструкция по развертыванию проекта на GitHub с телефона.
