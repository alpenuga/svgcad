# Развёртывание CAD-Мастер на GitHub Pages с телефона

## 1. Создание репозитория
1. Откройте github.com, войдите в аккаунт.
2. Нажмите «+» → **New repository**.
3. Имя: `cad-pwa`, видимость **Public**, нажмите **Create repository**.

## 2. Загрузка файлов
1. В репозитории: **Add file → Upload files**.
2. Загрузите все файлы проекта, сохраняя структуру папок:
   - `index.html`, `manifest.json`, `sw.js`, `install.md`
   - папка `css/` → `style.css`
   - папка `js/` → `core.js`, `stamp.js`, `toolbar.js`, `projections.js`,
     `ai-parser.js`, `library.js`, `tutorial.js`, `app.js`
   - папка `assets/icons/` → `icon.svg`
3. **Commit changes**.

> ⚠️ **Пути**: во всех файлах используются относительные пути `./`,
> это обязательно для GitHub Pages.

## 3. Включение GitHub Pages
1. В репозитории: **Settings → Pages**.
2. **Source**: *Deploy from a branch*.
3. **Branch**: `main`, папка **`/ (root)`**. **Save**.
4. Через 1–2 минуты: `https://<ваш-ник>.github.io/cad-pwa/`.

## 4. Установка на телефон
1. Откройте полученный адрес в Chrome или Safari.
2. Меню браузера → **Установить приложение** или **На главный экран**.
3. Иконка появится на рабочем столе, приложение работает офлайн
   (кроме распознавания фото).

## 5. Ключ Gemini
1. Получите ключ на https://aistudio.google.com/apikey.
2. В приложении: ⚙️ Настройки → вставьте ключ → **Сохранить и проверить**.
3. Ключ хранится в localStorage вашего телефона, никуда не передаётся
   кроме Google API.

## 6. Как обновить приложение после правок
1. Загрузите изменённые файлы (Upload files заменит их).
2. Откройте `sw.js` и **измените номер версии** `cad-v1` → `cad-v2`.
3. Закройте и снова откройте приложение на телефоне — оно обновится.

## 7. Проверка после установки
- ✅ Открывается лист А4 с рамкой и штампом
- ✅ Рисуются линия, круг, прямоугольник, дуга
- ✅ Кнопка «Формат» меняет лист А4/А3, портрет/ландшафт
- ✅ Распознавание фото возвращает JSON
- ✅ «Три основных вида» строит проекции
- ✅ «Библиотека» сохраняет/загружает детали
- ✅ На рабочем столе появилась иконка CAD-Мастер (синяя с чертежом)

## Возможные проблемы
| Симптом | Причина | Решение |
|:---|:---|:---|
| 404 на `index.html` | Pages не включён | Проверить Settings → Pages |
| Стили не грузятся | Пути `/` вместо `./` | Проверить `<link href="./css/style.css">` |
| SW не работает | Открыто по `file://` | Нужен https, только GitHub Pages |
| Ключ не проходит проверку | Ключ просрочен или модель недоступна | Создать новый на aistudio |
| ИИ возвращает ошибку 429 | Закончилась квота | Подождать или сменить модель в `ai-parser.js` |
